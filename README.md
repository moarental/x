# MOA SNS自動運用

X(Twitter)への宣伝ツイート自動投稿と、関連アカウントの自動フォローを行うリポジトリです。
Claude Codeのスケジュール済みクラウドエージェントが1時間ごとに `scripts/run.py` を実行し、
以下のタイミングで実際のアクションを行います。

- ツイート投稿: 前回投稿から約85時間(±ランダムなブレ)
- フォロー: 前回フォロー作業から約25時間(±ランダムなブレ)、名古屋のメンズエステ店舗・セラピスト関連の投稿を検索して見つけたアカウントを最大5件

## 必要な環境変数(シークレット)

Claude Codeの実行環境(Environment)に以下を設定してください。値はX Developer Portalで発行したものです。

- `X_API_KEY`
- `X_API_SECRET`
- `X_ACCESS_TOKEN`
- `X_ACCESS_SECRET`

いずれもこちらでは入力できないため、ご自身で設定をお願いします。

## フォルダ構成

- `content/posts.json` — ツイート文のローテーション。増やしたい場合はここに追記してください
- `images/` — ツイートに添付する画像。ここに画像をアップロードすると自動でローテーションに使われます
- `scripts/run.py` — 本体スクリプト
- `state.json` — 実行状態(最終投稿・フォロー時刻など)。スクリプトが自動更新します、手動編集不要です

## 検索クエリの調整

`scripts/run.py` 内の `SHOP_QUERIES` / `THERAPIST_QUERIES` を編集すると、フォロー対象を探す検索キーワードを変更できます。
